# 四张测试图像

本目录只保留本轮测试使用的三张铜丝模拟图和一张真实根系图。其他图像集合和历史数据清单不随本次公开仓库发布。

| 路径 | 尺寸（宽 × 高，px） | 内容 |
|---|---|---|
| `four_examples/original/input_1.png` | 2790 × 4688 | 贴合、共同根基铜丝 |
| `four_examples/original/input_2.png` | 2957 × 5159 | 重叠铜丝 |
| `four_examples/original/input_3.png` | 1426 × 3135 | 密集铜丝 |
| `four_examples/original/input_4.png` | 3401 × 4884 | 黑底白色真实根系 |

保留项目收到的完整分辨率附件字节，不进行缩放或重新压缩。这里的 `original` 指项目收到的输入版本，不代表未经处理的传感器原始数据。

输入哈希、尺寸、分割方法、根基修复开关和分析模型以 [analysis_parameters.json](four_examples/analysis_parameters.json) 为准。原图和参数共同用于复现：

```bash
python scripts/reproduce_four_examples.py
```

命令在仓库根目录运行。加 `--images 1` 可以先验证第一张，`--no-figures` 只导出数据。输出为运行生成的二值图、骨架、识别点、指标和软件结果图，不会写回原始测试图像。

## 尺度、真值和来源

四张图没有可确认的物理尺度，也没有完整独立实物测量真值。软件输出使用像素单位；自动得到的端点、分叉和交叉数量不能当作准确率验证的真值。疑似裁切端点并入可见端点，不重复累计。

测试图来自用户提供的附件，逐图完整上游来源和再分发条款尚未全部随附件提供。源码 MIT 许可和原创文档许可不自动覆盖图像数据；本说明不为未知上游权利重新指定开放许可证。正式引用和复用时须按原作者的实际来源、署名与许可要求处理。
