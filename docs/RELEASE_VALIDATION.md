# V1.0.0 发布检查

本次发行包含无激活码源码、Windows 便携程序、四张测试图和必要 Markdown。论文技术方案、HTML、公式字体、其他数据集合及历史分析结果不随本次仓库发布。

## 本次改动

- 新增默认关闭的粗根基封闭伪孔修复，提供预处理 GUI 和命令行入口。
- 保留三张铜丝和一张真实根系原图，运行参数记录于 `datasets/four_examples/analysis_parameters.json`。
- 技术文档及移除的数据在维护者本地备份，未从原始工作项目删除。
- 第三方许可文本集中保留为 Markdown；Windows 程序仍须完整保留运行文件。

## 验证原则

发行前必须运行算法回归、参数传递检查、冻结 EXE 自检及普通 GUI 启动检查。四张图按记录参数运行，核对二值图、骨架、识别点和指标是否一致。

外部铜丝图像不在精简仓库中，相应可选测试缺失数据时报告跳过。通过数和跳过数须分别报告，不能将跳过算作通过。合成几何测试通过不能直接证明真实根系量化准确。
